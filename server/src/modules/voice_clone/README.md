# voice_clone (сервер)

**Задача:** запись голоса + согласие → профиль голоса, удаление по запросу

- Публичный вход: `api.py`. Другие модули импортируют только его.
- Всё остальное — в `internal/`, снаружи не импортируется.
- Зависит от: shared.
- Тесты: `tests/`.

## Поставщики

По папке на внешний сервис в `internal/providers/`. Ключи — только из переменных окружения.
