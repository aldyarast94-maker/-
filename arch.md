# arch.md — карта проекта BubbleCast

> Статус схемы: **ЧЕРНОВИК v3 — ждёт ОК владельца.** Пока статус не «УТВЕРЖДЕНО», код не пишется.
> Эту карту меняют только с согласия владельца. Правила работы — `.claude/skills/arch-rules/SKILL.md`.

## 1. Что строим

**BubbleCast** (пакет `com.npcknows.bubblecast`) — «bubble» — пузырь с репликой,
«cast» — состав голосов: приложение раздаёт голоса пузырям.

Приложение для Android (Google Play, для всех), которое **озвучивает мангу, комиксы и манхвы**:
находит реплики, понимает, кто говорит и с какой эмоцией, и читает их голосами.
Можно читать глазами и слушать, а можно только слушать — например, за рулём.

Решения владельца:
- **Откуда комиксы:** с сайтов, из других приложений на телефоне, из файлов.
- **Язык:** тот, что на странице. Пока два — **русский и английский**. Перевода нет.
- **Голоса:** при первом запуске пользователь выбирает голос чтеца — **стандартный мужской,
  стандартный женский** или **свой голос** (бонус: читает текст с экрана, приложение
  запоминает голос). Выбор можно поменять в настройках.
- **Для кого:** все пользователи Google Play.
- **Два уровня:** Базовый бесплатно на телефоне + Профи по подписке (раздел 3) — утверждено.

## 2. Три закона фундамента

1. **Один модуль — одна задача — одна папка.** Задача модуля — одно предложение
   «берёт X → отдаёт Y». Если нужно слово «и» — это два модуля.
2. **Общее живёт в одном месте.** Код, нужный двум и более модулям, лежит только в `shared/`
   своей части (приложение или сервер). Копировать код между модулями **запрещено**.
3. **Данные между приложением и сервером описаны один раз** — в `contracts/`.
   Код типов генерируется из них и руками не правится.

## 3. Главное решение: два уровня озвучки

Для всех пользователей Google Play всё делать на сервере слишком дорого, да и без интернета
(в машине) ничего бы не работало. Поэтому так:

| | **Базовый** (бесплатно) | **Профи** (подписка) |
|---|---|---|
| Где работает | целиком на телефоне, без интернета | на телефоне + сервер |
| Поиск реплик и текста | модели на телефоне | vision-LLM на сервере |
| Кто говорит, эмоции | простые (по знакам «!», «?», капсу, форме пузыря) | по лицам, позе и смыслу |
| Голоса | один чтец: стандартный мужской или женский (RU и EN) | голоса персонажей с эмоциями + **свой голос** |
| Свой голос | бонус: пробная глава бесплатно, чтобы услышать себя | без ограничения проб |
| Приватность | картинки никуда не уходят | страница уходит на наш сервер для обработки |

Порядок обработки (`pipeline`) **один** и живёт в приложении. У каждого шага есть два
поставщика (provider): `local` — на телефоне, `cloud` — через сервер. Сервер — это только
облачные поставщики, своего порядка обработки у него нет.

## 4. Стек (решение и почему)

| Часть | Выбор | Почему |
|---|---|---|
| Приложение | **Kotlin + Jetpack Compose**, только Android | захват экрана, окно поверх других приложений, фоновая служба, звук на заблокированном экране — всё это родное Android. На iOS читать чужие приложения нельзя, так что Flutter ничего не даёт |
| Модули приложения | **Gradle-модуль на каждый модуль карты** | запрещённый импорт просто не соберётся: правила зависимостей проверяет компилятор |
| ИИ на телефоне | ONNX Runtime (поиск пузырей), OCR на телефоне (RU+EN), sherpa-onnx (голоса) | работает без сети |
| Звук | Media3 (MediaSession) | фон, экран блокировки, кнопки наушников и руля по Bluetooth, позже Android Auto |
| Сервер | **Python 3.12 + FastAPI** | весь серверный ИИ живёт в Python |
| Сервер: понимание страницы | vision-LLM (Claude) через адаптер | порядок реплик, говорящий, эмоция |
| Сервер: речь и свой голос | адаптер провайдера синтеза и клонирования голоса | провайдера можно сменить |
| Контракты | JSON Schema → генерация Kotlin и Python | одно описание данных |
| Вход и оплата | вход через Google, Google Play Billing | стандарт для Google Play |

Условие для всех моделей и голосов: **лицензия разрешает коммерческое использование**.
Многие модели для манги обучены на некоммерческих данных — их брать нельзя.

## 5. Откуда берутся страницы (три источника)

| Источник | Как | Чтение без рук |
|---|---|---|
| `source_files` | CBZ/ZIP/PDF/картинки с телефона | да — вся глава у нас |
| `source_web` | встроенный браузер: открываешь сайт, приложение берёт картинки главы, которые страница уже загрузила | да — вся глава у нас |
| `source_screen` | захват экрана поверх любого приложения (кнопка поверх экрана) | нет — листаешь сам, звук идёт следом |

Почему поверх других приложений нельзя без рук: Android не даёт листать чужое приложение
без службы специальных возможностей, а Google Play её для этого запрещает. Поэтому для дороги
нужен встроенный браузер или файлы. Приложения, которые запрещают снимать экран, при захвате
дают чёрный экран — так задумано Android, обходить это не будем.

## 6. Как это работает

```
 ИСТОЧНИК            ПРИЛОЖЕНИЕ                                           СЕРВЕР (только Профи)
 ────────            ──────────                                           ─────────────────────
 source_files ┐
 source_web   ├─► reading_session ─► reader (экран, позиция глаз)
 source_screen┘        │
                       ├─► pipeline ─► script ──────(cloud)──► api_client ══► api ─► vision
                       │      │      ─► characters
                       │      │      ─► cast
                       │      │      ─► text_prep
                       │      │      ─► tts ────────(cloud)──► api_client ══► api ─► speech
                       │      ▼
                       └─► narration ─► audio_session ─► динамик / наушники / машина
```

`pipeline` готовит страницы **на несколько вперёд**, чтобы звук был готов к моменту, когда ты дошёл.

Режимы (`narration`):
- **«Я веду»** — листаешь сам, звук догоняет видимые реплики (единственный режим для `source_screen`);
- **«Веди меня»** — звук идёт сам, экран прокручивается за ним, можно выключить экран (режим для дороги).

├─ server/                       ← Python
│  └─ src/
│     ├─ main.py                 ← только сборка модулей

### Устройство любого модуля

```
modules/<имя>/
├─ README.md     ← задача одним предложением, вход, выход, от кого зависит
├─ публичный вход ← Kotlin: public API модуля; Python: api.py. Другие модули берут только его
├─ internal/     ← всё остальное (в Kotlin — видимость internal)
├─ providers/    ← если есть: local/ и cloud/, по папке на поставщика
└─ tests/
```

## 8. Модули

### Приложение (`app/modules/`)

**Источники и экран**

| Модуль | Задача (берёт → отдаёт) | Зависит от | Статус |
|---|---|---|---|
| `source_files` | файлы пользователя → страницы главы | shared | план |
| `source_web` | адрес сайта во встроенном браузере → страницы главы | shared | план |
| `source_screen` | разрешение на захват экрана → кадры с экрана как страницы | shared | план |
| `overlay` | действия пользователя → кнопки поверх других приложений (старт, пауза, стоп) | shared | план |
| `reader` | страницы → показ на экране + видимая область + прокрутка по команде | shared | план |
| `library` | прочитанное → история и место, где остановился | shared | план |

Все источники отдают страницы через **один интерфейс `PageSource` в `shared/`**.
Никто не знает конкретный источник, кроме сборки `app/`.

**Обработка страницы** (у шагов с поставщиками есть `local` и `cloud`)

| Модуль | Задача (берёт → отдаёт) | Зависит от | Статус |
|---|---|---|---|
| `pipeline` | страница → готовые к проигрыванию реплики. **Только вызывает шаги по порядку** | shared, script, characters, cast, text_prep, tts | план |
| `script` | картинка страницы → сценарий: реплики с рамкой, текстом, языком, типом, говорящим, эмоцией | shared, api_client | план |
| `characters` | «говорящий» со страницы → один и тот же персонаж через всю книгу | shared | план |
| `cast` | персонаж → голос (по полу/возрасту/характеру; выбор пользователя важнее) | shared | план |
| `text_prep` | текст реплики → произносимый текст (ударения, ё, числа, звуки вроде «БА-БАХ»); RU и EN | shared | план |
| `tts` | произносимый текст + голос + эмоция → звук | shared, api_client | план |

Типы реплик: `dialogue` (речь), `thought` (мысль), `narration` (текст автора), `sfx` (звук),
`sign` (надпись на фоне — по умолчанию не читается).

**Чтение и звук**

| Модуль | Задача (берёт → отдаёт) | Зависит от | Статус |
|---|---|---|---|
| `reading_session` | выбранный источник + позиция чтения → команды pipeline, reader и narration. **Только связывает** | shared, reader, pipeline, narration, overlay, library | план |
| `narration` | готовые реплики + видимая область → что и когда играть, какую реплику подсветить | shared, audio_session | план |
| `audio_session` | очередь звуков → игра в фоне, экран блокировки, кнопки наушников и руля | shared | план |
| `drive_mode` | действия пользователя → экран для дороги: крупные кнопки, можно без экрана | shared, reading_session | план |

**Голоса, аккаунт, настройки**

| Модуль | Задача (берёт → отдаёт) | Зависит от | Статус |
|---|---|---|---|
| `onboarding` | первый запуск → выбранный голос чтеца (мужской / женский / свой) + объяснение разрешений | shared, my_voice, settings | план |
| `voices` | персонажи книги → экран выбора голоса каждому | shared, characters, cast | план |
| `my_voice` | запись голоса пользователя + согласие → свой голос (номер профиля) | shared, api_client | план |
| `account` | вход через Google → пользователь и его токен | shared, api_client | план |
| `billing` | покупка в Google Play → уровень (Базовый/Профи) и остаток лимита | shared, api_client | план |
| `settings` | действия пользователя → сохранённые настройки | shared | план |
| `api_client` | запросы модулей → обмен с сервером по контрактам | shared | план |

### Сервер (`server/src/modules/`) — только для Профи

| Модуль | Задача (берёт → отдаёт) | Зависит от | Статус |
|---|---|---|---|
| `api` | HTTP-запросы → вызовы модулей и ответы по контрактам (проверка входа и лимита перед вызовом) | shared, accounts, billing, vision, speech, voice_clone | план |
| `accounts` | токен Google → пользователь | shared | план |
| `billing` | чек покупки Google Play → подписка и лимит | shared | план |
| `vision` | картинка страницы → сценарий (как `script`, но с эмоциями и персонажами по смыслу) | shared, cache | план |
| `speech` | произносимый текст + голос + эмоция → звук | shared, cache | план |
| `voice_clone` | запись голоса + согласие → профиль голоса, удаление по запросу | shared | план |
| `cache` | ключ (хеш страницы/реплики/голоса) → готовый результат или «нет» | shared | план |

## 9. Правила зависимостей

- Модуль импортирует только `shared/` и **публичный вход** модулей из колонки «Зависит от».
  В приложении это зеркально записано в `build.gradle.kts` модуля — лишний импорт не соберётся.
- Модули одного уровня друг о друге **не знают**. Их связывают только `pipeline` (страница)
  и `reading_session` (чтение целиком).
- Циклы запрещены. `shared/` не зависит ни от одного модуля.
- Приложение и сервер не делят код — только `contracts/`.

## 10. Google Play и закон (влияет на схему)

- **Захват экрана:** разрешение спрашивается каждый раз, работает фоновая служба типа
  `mediaProjection` со значком в шторке. Службу специальных возможностей не используем.
- **Кнопки поверх приложений:** разрешение «поверх других окон», понятное объяснение перед запросом.
- **Свой голос:** только голос самого пользователя — перед записью он читает фразу согласия
  с экрана. Голос не передаётся другим, удаляется одной кнопкой. Голоса известных людей не делаем.
- **Чужие комиксы:** приложение озвучивает то, что пользователь сам открыл. Страницы не храним
  на сервере дольше обработки и никому не раздаём. Кэш звука — только на телефоне пользователя.
- **За рулём:** в режиме дороги на экран смотреть не нужно, всё управляется кнопками наушников/руля.
- **Данные:** форма Data safety и политика конфиденциальности (можно разместить на GitHub Pages
  в репозитории `dragonlegacy-privacy`, как сделано для Dragon Legacy).
