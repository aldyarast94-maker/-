# script

**Задача:** картинка страницы → сценарий: реплики с рамкой, текстом, языком, типом, говорящим, эмоцией

- Публичный вход: `ScriptReader` (`src/main/kotlin/com/npcknows/bubblecast/script/ScriptReader.kt`).
  Другие модули используют только его.
- Всё остальное — в пакете `internal/` с видимостью `internal`.
- Зависит от: shared, api_client.
- Вид: `bubblecast.android`.
- Тесты: `src/test/`.

## Поставщики

- `internal/providers/local/` — на телефоне, без сети (Базовый).
- `internal/providers/cloud/` — через `api_client` (Профи).

## Порядок чтения (готово)

`internal/ReadingOrder` — свой геометрический алгоритм: рамки собираются в ряды по высоте, ряды сверху вниз,
внутри ряда справа налево (манга) или слева направо (комикс); вебтун — сверху вниз.
Готовые решения не подошли: Kumiko и детектор inkwell — AGPL, Magi — только для исследований.

## Поставщик local: выбор моделей (исследование 2026-11-27, ждёт ОК владельца)

| Шаг | Модель | Лицензия | Размер | Риск |
|---|---|---|---|---|
| Пузыри и текст | ogkalu/comic-text-and-bubble-detector (RT-DETR-v2), ONNX int8 | Apache-2.0 (код и веса) | 44 МБ (есть 11 МБ, не описан) | данные для обучения не раскрыты → до релиза спросить автора или переобучить на своих |
| Строки внутри пузыря | PP-OCRv5_mobile_det, ONNX | Apache-2.0 | ~5 МБ | не настроен на комиксы |
| Текст RU + EN | eslav_PP-OCRv5_mobile_rec, ONNX (одна модель на оба языка) | Apache-2.0 | ~8 МБ | точность на комиксных шрифтах не проверена — нужен свой тестовый набор |
| Запуск | ONNX Runtime Android | MIT | — | — |

Не подходят: всё на Ultralytics YOLO (AGPL), comic-text-detector (GPL + Manga109), модели на Manga109
(некоммерческие), Google ML Kit (нет кириллицы).
