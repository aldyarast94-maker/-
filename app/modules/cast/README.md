# cast

**Задача:** персонаж → голос (по полу/возрасту/характеру; выбор пользователя важнее)

- Публичный вход: `Caster` (`src/main/kotlin/com/npcknows/bubblecast/cast/Caster.kt`).
  Другие модули используют только его.
- Всё остальное — в пакете `internal/` с видимостью `internal`.
- Зависит от: shared.
- Вид: `bubblecast.kotlin`.
- Тесты: `src/test/`.

## Как работает сейчас

1. Голос, назначенный пользователем персонажу.
2. Базовый: всё читает чтец из настроек; если он не говорит на языке страницы — стандартный голос того же пола.
3. Профи: голос по полу персонажа, разным персонажам — разные голоса.

Список голосов (`catalog`) и голос чтеца (`narrator`) передаёт сборка app/ — cast не знает о tts и settings.
