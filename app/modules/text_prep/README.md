# text_prep

**Задача:** текст реплики → произносимый текст (ударения, ё, числа, звуки вроде «БА-БАХ»); RU и EN

- Публичный вход: `TextPreparer` (`src/main/kotlin/com/npcknows/bubblecast/text_prep/TextPreparer.kt`).
  Другие модули используют только его.
- Всё остальное — в пакете `internal/` с видимостью `internal`.
- Зависит от: shared.
- Вид: `bubblecast.android` + `bubblecast.onnx` (модель ударений).
- Тесты: `src/test/`.

## Что уже умеет (этап 2)

- склеивает строки пузыря и переносы «ПРИ-/ВЕТ»;
- убирает значки (♥ ♪ ~ …), сжимает «!!!», «?!?!», «Аааааа», «.....»;
- снимает комиксный КАПС и путаницу регистра после распознавания («БытЬ» → «быть»), регистр предложений; в английском «I» остаётся заглавной;
- числа и проценты словами, RU и EN, с правильной формой слова («3 процента», «21 000 → двадцать одна тысяча»).

- ударения и ё в русском (`internal/stress/RussianStress`): знак U+0301 после ударной гласной, «е» → «ё»;
  без знака над «ё» и в словах с одной гласной. Неуверенные омографы («стоит») остаются без знака.

## Ещё нет

- падежи числительных («с 5 друзьями» прочитается «с пять друзьями»);
- омографы по смыслу («за́мок / замо́к» в контексте) — модель смотрит на слово, не на предложение.
