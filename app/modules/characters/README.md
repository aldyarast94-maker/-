## Как работает сейчас

Персонаж = подсказка `speaker_hint` из сценария, одна и та же подсказка в книге — один персонаж.
Текст автора, звуки и надписи — «чтец». Без подсказки (Базовый) — «кто-то», один на книгу.
Хранится в памяти; между запусками — позже, вместе с library.
