# models

**Задача:** каталог моделей → файлы на телефоне: скачать при первом запуске с докачкой, проверить контрольную сумму, показать прогресс

- Публичный вход: `ModelStore` (`src/main/kotlin/com/npcknows/bubblecast/models/ModelStore.kt`).
  Другие модули используют только его; файлы моделей получают через `ModelStore.locator`.
- Всё остальное — в пакете `internal/` с видимостью `internal`.
- Зависит от: shared.
- Вид: `bubblecast.kotlin` (только java.net и java.io — работает и на телефоне, и в тестах).
- Тесты: `src/test/` (локальный HTTP-сервер, обрыв и докачка, битый файл).

## Как работает

Список файлов — `shared/ModelCatalog` (адрес с зафиксированной ревизией, sha256, размер, лицензия).
Скачивание: `<файл>.part` → докачка по `Range` после обрыва → проверка sha256 → переименование на место → метка `.ok`.
Битый файл качается заново один раз, потом — ошибка.
