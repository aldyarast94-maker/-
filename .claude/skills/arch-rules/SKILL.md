# Правила перед каждой правкой

Источник истины — `arch.md` в корне. Если правило здесь и карта расходятся — остановись и спроси владельца.

## 0. Можно ли вообще писать код

- Открой `arch.md`. Если статус схемы не **«УТВЕРЖДЕНО»** — код не пишется. Можно только
  обсуждать и предлагать правки карты.
- Модуль, в который идёт правка, должен быть в таблице модулей `arch.md`. Нет модуля —
  **стоп**: предложи новую строку таблицы (имя, задача «берёт → отдаёт», зависимости) и жди ОК.
- Правка самой `arch.md` или этого файла — только после ОК владельца.

## 1. Один модуль — одна задача — одна папка

- Определи **один** модуль, к которому относится правка. Правка трогает только его папку.
- Исключения, каждое называется в отчёте отдельно: `shared/`, `contracts/`, `tools/`,
  `.github/`, сборка (`app/app/`, `server/src/main.py` — только подключение модулей),
  `app/build-logic/` и `app/gradle/libs.versions.toml`.
- Если новый код не укладывается в задачу модуля из `arch.md` (нужно слово «и») —
  это новый модуль. Стоп, предложи его.
- `pipeline`, `reading_session`, сборка `app/app/` и `main.py` только вызывают модули. Своей логики в них нет.
- Настройки сборки — только в `build-logic/`, версии — только в `libs.versions.toml`.
  В `build.gradle.kts` модуля: одна строка плагина и зависимости из карты.
- Новый модуль приложения подключается сам, когда появляется его папка в `app/modules/`.

## 2. Копировать запрещено

Перед тем как написать функцию, тип, константу или текст:

1. Поищи похожее в `shared/` и во всех `modules/` (по смыслу и по имени, `Grep`).
2. Есть в `shared/` → используй.
3. Есть внутри другого модуля и нужно тебе → **перенеси в `shared/`**, замени в старом месте
   на импорт. Отдельный шаг, назови его в отчёте. Не копируй «пока».
4. Данные, которые ходят между приложением и сервером, описываются **только** в `contracts/`.
   После правки контракта — перегенерируй `contracts_gen/`. Папки `contracts_gen/` руками не правятся.
5. Константы (адреса, лимиты, названия эмоций, типы реплик) — в одном месте, не литералами по коду.

`shared/` — только то, что нужно двум и более модулям. Код одного модуля в `shared/` не кладут.

## 3. Зависимости

- Импортируй только `shared/` и **публичный вход** модулей из колонки «Зависит от» в `arch.md`.
- Никогда не импортируй `internal/` чужого модуля.
- Модули одного уровня друг друга не импортируют — связь только через `pipeline`.
- Новая зависимость, которой нет в `arch.md`, — стоп, предложи правку карты.
- В приложении зависимости модуля в `build.gradle.kts` совпадают с колонкой «Зависит от».
  Добавлять туда модуль, которого нет в карте, нельзя.
- Источники страниц знает только сборка `app/`; остальные работают через `PageSource` из `shared/`.
- Внешние сервисы (LLM, синтез речи) — только через `providers/` своего модуля.
  Шаг обработки = один модуль с поставщиками `local/` и `cloud/`, а не два модуля.
- `pipeline` один и живёт в приложении. На сервере порядка обработки нет.

## 4. Секреты и данные

- Ключи API только на сервере, из переменных окружения. В приложении и в git ключей нет.
- Картинки и тексты пользователя не уходят никуда, кроме провайдеров, указанных в `arch.md`.
- Уровень «Базовый» работает без сети: в его поставщиках `local/` нет сетевых вызовов.
- Модели и голоса — только с лицензией для коммерческого использования; лицензию указывать в README модуля.
- Требования Google Play из раздела 10 `arch.md` (захват экрана, свой голос, без службы
  специальных возможностей) не нарушаются ни в одной правке.

## 5. Размер

- Файл — до ~300 строк, функция — до ~50. Больше — дели внутри модуля.
- Модуль разросся до двух задач — предложи разделить.

## 6. В той же правке

- Обнови `README.md` модуля, если поменялся вход, выход или зависимости.
- Обнови статус модуля в `arch.md` (план → в работе → готово) — это разрешено без отдельного ОК.
- Тесты модуля лежат в его `tests/`.

## 7. Проверка после правки (ответь себе перед отчётом)

Запусти и добейся нуля ошибок (то же запускает CI):

    python3 tools/check_arch.py            # карта = папки = зависимости = импорты
    python3 tools/gen_contracts.py --check # контракты сгенерированы
    cd app && ./gradlew assembleDebug test # приложение (ANDROID_HOME должен быть задан)
    cd server && pytest -q                 # сервер

- [ ] Правка внутри одного модуля (+ названные исключения)?
- [ ] Ничего не скопировано — поиск дублей сделан?
- [ ] Импорты только разрешённые, `internal/` чужих не тронут?
- [ ] Контракты правились только в `contracts/`, `contracts_gen/` перегенерирован?
- [ ] README модуля и статус в `arch.md` актуальны?

В отчёте владельцу: какой модуль, что изменено, что перенесено в `shared/` (если было).
